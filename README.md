## My Design Decisions

1. Colors: I chose this colour scheme because I like purple. I also find it more comfortable to look at than other colour combinations

2. Responsive layout: I used three project columns on desktop because larger screens have enough space to display all three projects side by side. This makes the website look organized and allows users to compare projects easily.
On mobile, I used one column because the screen is smaller. This makes the project cards easier to read and prevents the content from becoming too narrow. It also improves the user experience by making the website responsive on different devices.

3. Projects: I added these three projects to show my experience and skills in different areas of IT. The first project, Interactive and Web Application Development, demonstrates my HTML, CSS, JavaScript, and React skills. The second project, Principles of Programming 2, shows my Python programming skills and experience in developing simple games. The third project, Telegram Bot, represents my experience in creating a useful application for KBTU students. I chose these projects because they show my progress as an IT student and my ability to apply what I have learned in practice.
